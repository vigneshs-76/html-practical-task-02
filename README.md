# SnapFrame Photography Studio

A responsive three-page local business website created using **Bootstrap 5.3** and custom CSS for a Web Development assignment.

## Business details
- **Business name:** SnapFrame Photography Studio
- **Business type:** Photography Studio
- **Pages:** Home, Services and Contact

## Files and folders

```text
snapframe-photography-website/
├── index.html
├── services.html
├── contact.html
├── style.css
├── images/
│   └── studio.svg
└── README.md
```

## Bootstrap component selected

**Accordion** — used for the Frequently Asked Questions section on the Home page. It contains four questions.

Official documentation:
https://getbootstrap.com/docs/5.3/components/accordion/

## Bootstrap setup

Bootstrap 5.3.3 CSS is included in the `<head>` of all three HTML pages. The Bootstrap bundle JavaScript is included before the closing `</body>` tag on every page. The viewport meta tag and custom `style.css` are also included on every page.

## How to run

1. Download or clone this repository.
2. Keep all files and the `images` folder in the same project folder.
3. Open `index.html` in a browser.
4. Use the navigation links to visit Services and Contact.
5. Internet access is required to load Bootstrap from its CDN.
